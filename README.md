# Тестирование математических операций с помощью Pytest

В этом проекте реализовано тестирование базовых математических вычислений с использованием фреймворка `pytest`.

## Подготовка окружения

Для запуска теста выполните следующие шаги:

1. **Создайте и активируйте виртуальное окружение:**
   * **Windows:**
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```
   * **macOS / Linux:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

2. **Установите необходимые зависимости:**
   ```bash
   pip install pytest
   ```

## 📝 Структура тестового файла

Убедитесь, что ваш тест находится в файле с префиксом `test_` (например, `test_math.py`). 
Код внутри файла должен быть обернут в функцию, имя которой также начинается с `test_`:

```python
def test_math_operation():
    assert 2 + 2 == 4
```

## 🚀 Запуск тестов

Вы можете запустить тест несколькими способами:

### Способ 1. Стандартный запуск через Терминал
Выполните команду в корневой папке проекта:
```bash
pytest
```

### Способ 2. Тихий режим (Краткий вывод)
Если вы хотите скрыть служебную информацию и увидеть только результат:
```bash
pytest -q
```

### Способ 3. Через графический интерфейс PyCharm
1. Откройте файл `test_math.py`.
2. Нажмите правой кнопкой мыши внутри кода функции `test_math_operation`.
3. Выберите пункт **Run 'pytest in test_math.py'** (иконка с зеленым треугольником).
